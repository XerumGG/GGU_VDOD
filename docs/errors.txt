GGU_VDOD MASTER ERROR DICTIONARY
=================================
21 runtime error categories. Each shows what the app tells the user and what to do.
Format: [CODE] Title | Trigger -> Fix (sound)

[ERR_NET_DISCONNECTED] Network Connection Lost
  Trigger: reset/timeout/DNS errors -> Check Wi-Fi, click 'Retry Download'. (HAND)

[ERR_DISK_FULL] Disk Space Full
  Trigger: Errno 28 / free space too low -> Free space or pick another drive. (STOP)

[ERR_CLOUDFLARE_403] Cloudflare Protection Blocked
  Trigger: 403 + anti-bot/impersonate -> Import browser cookies. (EXCLAMATION)

[ERR_RATE_LIMITED_429] Server Rate Limited (HTTP 429)
  Trigger: 429 / too many requests -> Wait 1-2 min, retry. (EXCLAMATION)

[ERR_AGE_RESTRICTED] 18+ Age Verification Required
  Trigger: age gate -> Import age-verified browser cookies. (ASTERISK)

[ERR_PRIVATE_VIDEO] Private or Member-Only Content
  Trigger: private/members-only -> Use cookies from an account with access. (EXCLAMATION)

[ERR_BOT_CHECK] Platform Sign-In Verification
  Trigger: "confirm you're not a bot" / use --cookies -> Set Browser cookies or Account session. (EXCLAMATION)

[ERR_YOUTUBE_403] YouTube Blocked the Download (403)
  Trigger: YouTube 403 / unable to download video data -> Retry (auto alternate clients); else browser cookies or plain watch?v= link. (EXCLAMATION)

[ERR_VIDEO_DELETED_404] Video Removed or Deleted (404)
  Trigger: 404 / unavailable / removed -> Check link in browser or find a mirror. (HAND)

[ERR_GEOBLOCKED] Country / Regional Block
  Trigger: not available in your country / 451 -> Use an allowed-country proxy/VPN. (EXCLAMATION)

[ERR_FFMPEG_MISSING] FFmpeg / FFprobe Binary Missing
  Trigger: ffmpeg not found -> Check D:\GGU_VDOD\ffmpeg\ or Browse FFmpeg. (STOP)

[ERR_FORMAT_UNAVAILABLE] Format / Resolution Unavailable
  Trigger: requested format not available -> 'Best available' or List Formats. (ASTERISK)

[ERR_PERMISSION_DENIED] Folder Access Denied
  Trigger: WinError 5 / access denied -> Pick a user folder (Downloads/Videos). (STOP)

[ERR_POSTPROCESS_FAILED] Conversion / Merge Step Failed
  Trigger: postprocessing error / invalid input data -> Retry once, then switch format or reset codec fields to Auto. (EXCLAMATION)

[ERR_CORRUPT_STREAM] Media Stream Integrity Failed
  Trigger: 0-byte / integrity check failed -> Retry to re-fetch segments. (HAND)

[ERR_DPAPI_COOKIE_LOCK] Browser Cookie Database Locked
  Trigger: DPAPI decrypt / cookie copy failed -> Close the browser or use cookies.txt. (EXCLAMATION)

[ERR_PROXY_FAILED] Proxy Connection Failed
  Trigger: proxy error / 407 -> Check host/port/credentials or clear proxy. (HAND)

[ERR_FRAGMENT_FAILED] Stream Fragment Download Drop
  Trigger: HLS/DASH fragment failed -> Retry (auto-resumes from last fragment). (EXCLAMATION)

[ERR_GITHUB_RATE_LIMIT] Update Check Temporarily Blocked
  Trigger: 403 rate limit on api.github.com -> Wait ~1h or download installer manually. App also falls back to the quota-free Releases page. (EXCLAMATION)

[ERR_HTTP_FORBIDDEN] Access Denied by Server (403)
  Trigger: generic 403 -> Load browser cookies and retry; verify link in browser. (EXCLAMATION)

[ERR_UNHANDLED_EXCEPTION] Unexpected Application Error
  Trigger: anything else -> Crash report recorded; Copy Technical Details / retry. (STOP)
